## 🚀 Projetos

### BelaAgenda: agendamento para salões
Sistema com portal para a cliente, painel para a dona, logins com permissões por profissional, cópia no Google Agenda e avisos por e-mail.
Fluxo: cliente ou painel → API em Node.js → Airtable, Google Calendar e e-mails. Bot de WhatsApp com Gemini em preparação.

### Automação de atendimento de RH por e-mail
Fluxo no Make que responde automaticamente, assim que o e-mail chega, às dúvidas frequentes de colaboradores sobre benefícios como vale-refeição e convênio, aliviando a demanda do RH.

### Assistente de redação com IA generativa
Protótipo no Make com modelo de linguagem (LLM): a partir de tópicos, tipo de texto e tom de voz informados pelo usuário, gera e-mails, resumos de reunião e mensagens para WhatsApp corporativo, de forma coerente e organizada, para o RH ganhar tempo.

### Chatbot com IA e Base de Conhecimento
Fluxo no Make que recebe mensagens no Telegram, consulta conteúdo no Google Drive e responde com Gemini.

### Loja de Pratas

## 🧠 Como eu trabalho com IA
- **Prompt engineering aplicado:** prompts com memória da conversa, catálogo de serviços, data atual e resposta estruturada em JSON, para o chatbot marcar horários sozinho.
- **IA com verificação:** uso IA para acelerar o código e confiro com testes automatizados, leitura de logs e testes com dados reais.
- **Segurança e custo desde o começo:** chaves só no servidor, limite de pedidos, validação de dados e cache para economizar chamadas de API.
